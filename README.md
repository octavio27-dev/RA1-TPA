# Reservas de cancha sintética (Colas y Pilas)

## Cómo ejecutarlo en Visual Studio Code
1. Instala Node.js (https://nodejs.org, versión LTS).
2. En VS Code: Archivo > Abrir carpeta > `reservas-cancha`.
3. Abre la terminal (Ctrl + ñ) y ejecuta:
       npm install
       npm start
4. Abre http://localhost:3000 en el navegador.

## Estructura
- server.js          -> Backend, clases Cola (FIFO) y Pila (LIFO)  [Integrante 3]
- public/index.html  -> Vistas y formularios                       [Integrante 1]
- public/style.css   -> Estilos                                    [Integrante 1]
- public/app.js      -> Validaciones y eventos                     [Integrante 2]
- docs/              -> Historias de usuario, diagramas, UML       [Integrantes 4 y 5]
